============================================================
 タイトル画面の仕組み（かんたん版）
============================================================

■ ひとことで言うと
  「ゲームと同じステージで、キャラが技を見せ続け、
    その上にロゴ・メニュー・火の粉を重ねている」画面。

■ 画面を作っている部品（Src/Application/GameObject/Title/ の中）

  TitleChara   … 技を見せ続けるキャラ
  TitleCamera  … キャラの周りをゆっくり動くカメラ
  TitleEmber   … 下から舞い上がる火の粉
  TitleUI      … ロゴ・メニュー・操作説明・フェード
  （背景の地面・空・廃墟は、ゲーム画面と同じものを使っている）


------------------------------------------------------------
1. TitleChara：キャラが技を見せ続ける
------------------------------------------------------------

  「台本」を用意して、その順番にアニメーションを再生している。

    構え（2.5秒） → 攻撃1の4連撃
    構え（2.5秒） → 攻撃3の4連撃
    構え（2.5秒） → 攻撃5の4連撃
    → 最初に戻って、ずっと繰り返す

  ・連撃は、アニメーションの途中（25フレーム目）で次の段に移るので、
    途切れずにつながって見える。最後の段だけは最後まで見せる。
  ・振り始め（10フレーム目）に、ゲームと同じ斬撃エフェクトを出す。
  ・踏み込む技でも、キャラはその場から動かない。


------------------------------------------------------------
2. TitleCamera：カメラがゆっくり動き続ける
------------------------------------------------------------

  ・最初の3秒：遠く・高い所から、キャラに向かって寄ってくる。
  ・その後  ：キャラの周りを、左右・前後・上下にゆらゆら動き続ける。

  ゆらゆらの正体は sin（サイン）。
  sin は「-1 → 0 → +1 → 0 → -1 …」と、行ったり来たりを繰り返す数。
  これを「回り込む角度」「距離」「高さ」の3つに使い、
  3つの速さをバラバラにしているので、同じ動きの繰り返しに見えにくい。

  また、カメラはキャラの少し左を見ている。
  だからキャラが画面の右寄りに映り、空いた左側にロゴとメニューを置ける。


------------------------------------------------------------
3. TitleEmber：火の粉が舞い上がり続ける
------------------------------------------------------------

  ・小さな火の粉 70個 と、大きくぼんやりした光の玉 10個。
  ・1粒ごとに「位置・速さ・大きさ・寿命」をランダムに決める。
  ・毎フレーム、少し上に動かし、左右にゆらゆらさせる。
  ・寿命が来たら（または画面の上に出たら）、画面の下から出し直す。
    → これで、ずっと途切れずに舞い上がる。
  ・生まれる時と消える時は1秒かけて明るさを変えるので、パッと出たり消えたりしない。

  「加算合成」で描いている。
  これは色を足し算する描き方で、重なるほど明るくなる（光の表現向き）。
  黒は足しても変わらないので、画像の黒い部分は透明に見える。


------------------------------------------------------------
4. TitleUI：ロゴとメニュー
------------------------------------------------------------

■ 最初の約3秒で、順番に現れる

    0.0秒～  黒い画面から明るくなる。上下に黒い帯が入ってくる
    0.5秒～  ロゴ「BRAVER」が、大きい状態から縮みながら現れる
    1.5秒    ロゴがキラッと光る
    1.3秒～  ロゴの下に光の線が伸びる
    2.3秒～  メニューが左から滑り込んでくる
    3.0秒～  メニューを選べるようになる
    （Enter を押すと、この演出を飛ばせる）

■ その後も動き続けるもの

  ・ロゴの後ろの光が、呼吸するように明るくなったり暗くなったりする
  ・ロゴの下の線の上を、ときどき光が走る
  ・選んでいる項目の両側の光の点が、左右に揺れる
  ・カーソルは、選んだ項目までスッと移動する
  ・操作説明を開いている時、画面の下の「戻る」の案内が、ゆっくり点滅する

■ メニュー

  START     … 選んだ項目が点滅 → 画面が暗くなる → ゲーム画面へ
  CONTROLS  … 操作説明を開く（Enter か BackSpace で閉じる）
  EXIT      … 画面が暗くなる → ゲーム終了

  操作：W / S（↑ / ↓）で選ぶ、Enter / Space / 左クリックで決定

■ 画面全体の演出

  ・画面の四隅を少し暗くしている（真ん中に目が行くように）
  ・上下の黒い帯で、映画のような雰囲気にしている


------------------------------------------------------------
5. よく使っている考え方
------------------------------------------------------------

  ■ 進み具合（0 → 1）
     「〇フレーム目から△フレームかけて 0 → 1 になる数」を作り、
     それを透明度や大きさに使っている。
     例：透明度に使う → だんだん見えてくる
         大きさに使う → だんだん大きく（小さく）なる

  ■ スッと動いて、ふわっと止まる
     進み具合をそのまま使うと、動きが機械的になる。
     最初は速く、最後はゆっくりになるよう変換してから使っている。

  ■ 目標に少しずつ近づける
     毎フレーム「目標までの残りの20%」だけ動かす。
     遠いうちは速く、近づくとゆっくりになり、なめらかに止まる。
     （カーソルの移動や、メニュー項目の大きさの変化に使っている）


------------------------------------------------------------
6. 調整したいとき
------------------------------------------------------------

  構えている時間を変えたい      → TitleChara.cpp   の kIdleHoldFrame
  見せる攻撃を変えたい          → TitleChara.cpp   の kShowAttackTypes
  カメラを近く・遠くしたい      → TitleCamera.cpp  の kDistance
  カメラが壁にめり込む          → TitleCamera.cpp  の kDistance か kYawSwingDeg を小さく
  キャラとロゴが重なる          → TitleCamera.cpp  の kFrameOffset
  火の粉の数・色を変えたい      → TitleEmber.cpp   の kEmberNum / kEmberColor
  ロゴの文字・位置を変えたい    → TitleUI.cpp      の kLogoText / kLogoPos
  メニューの位置を変えたい      → TitleUI.cpp      の kMenuX / kMenuTopY

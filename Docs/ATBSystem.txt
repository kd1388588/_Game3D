============================================================
 バトルの仕組み（FF7リメイク風）の説明
============================================================

■ 一言で
  ・E キーで「オペレーター」と「パニッシャー」の2つのモードを切り替える。
    オペレーターの左クリックは攻撃01、パニッシャーは攻撃02。
  ・攻撃を当てると ATB ゲージ（2本）がたまる。
    F キーで「ATB コマンド」を開くと時間がゆっくりになり（10分の1）、
    攻撃04（ゲージ1本）・攻撃05（ゲージ2本）から技を選ぶと、最後の段まで自動で出す。
    使った後は CT（クールタイム）があり、しばらく同じ技は使えない。
  ・攻撃05を使った後は、5秒間オペレーターに固定される（E キーで切り替えられない）。
  ・右クリックで回避。Shift は移動中ならダッシュ、止まっていればガード。
  ・攻撃が当たると、ヒットストップ（一瞬止まって画面が揺れる）がかかる。


------------------------------------------------------------
 1. 操作
------------------------------------------------------------
  E　　　　　：モード切り替え（オペレーター ⇔ パニッシャー）
  左クリック ：攻撃（オペレーターは攻撃01、パニッシャーは攻撃02のコンボ）
  右クリック ：回避（パニッシャーのままでも回避できる。そのかわりパニッシャーは攻撃が遅く、受けるダメージが多い。
                     PlayerState.cpp の kEvadeReturnsToOperator を true にすると、FF7R のクラウドと同じく
                     オペレーターに戻ってから回避する）
  ホイール / R：ロックオン（近くの敵に視点を合わせる。もう一度押すと外す）
  F　　　　　：ATB コマンドを開く・閉じる（開いている間は時間がゆっくりになる）
      メニューの中：W / S（矢印キー）で選ぶ、左クリック・Enter・Space で決定、
                    右クリック・F・BackSpace で閉じる、1・2キーでその技をすぐ決定
      ・攻撃04（ATB ゲージ1本、CT 3秒）
      ・攻撃05（ATB ゲージ2本、CT 8秒。使った後5秒オペレーター固定）
  Shift　　　：移動中はダッシュ（速く走る）、止まっている時はガード
  Space　　　：ジャンプ


------------------------------------------------------------
 2. 2つのモードの違い
------------------------------------------------------------
                    オペレーター          パニッシャー
  左クリックの攻撃  攻撃01                攻撃02
  移動の速さ        普通（1.0倍）         少し遅い（0.7倍）
  攻撃のダメージ    普通（1.0倍）         重い（1.5倍）
  ATB（時間）       少しずつたまる        たまらない
  ATB（当てた時）   +12                   +24（2倍）
  ヒットストップ    普通                  少し長い（重い攻撃に見せる）


------------------------------------------------------------
 3. ATB コマンド（F キー）
------------------------------------------------------------
  ・F キーでメニューを開くと、時間が10分の1の速さになる（キャラ・敵・エフェクトがゆっくり動く）。
    画面が少し暗くなり、右下にメニューが出る。敵はその間、攻撃してこない。
  ・選べる技は 攻撃04（ゲージ1本、CT 3秒）と 攻撃05（ゲージ2本、CT 8秒）。
    ゲージが足りない・CT 中の技は灰色で、選んでも出ない（CT の残りは青い線で表示）。
  ・技を選ぶとメニューが閉じて時間が元に戻り、選んだ技を最後の段まで自動で出す。
  ・攻撃05を使った後は5秒間オペレーターに固定（モードの文字の下に赤い線が出て、短くなっていく）。
  ・アビリティの攻撃はダメージ 1.5倍。当てても ATB ゲージはたまらない（無限に出せないように）。
  ・アビリティの攻撃を受けた敵は、のけぞり続ける（その間は攻撃してこない）。
  ・攻撃05の3段目は、再生速度を少し下げている（0.9倍）。


------------------------------------------------------------
 4. ガードとダッシュ（Shift）
------------------------------------------------------------
  ・止まっている時に Shift を押している間はガード。
    受けるダメージが 2割になり、のけぞらない（画面のモードの文字の横に GUARD と出る）。
    アニメーションは Sequence2/08_Hit/14_Block の「構える（Start）→ 構えたまま（Loop）→ 解く（End）」。
    攻撃を受け止めた時は「受け止める（Hit）」を再生し、Shift を押したままなら構えに戻る。
  ・ガードを構えた後に移動キーを押すと、構えたまま歩ける（普段の走る速さの半分）。
    歩いている間はカメラの方を向いたままで、移動の方向に合わせて8方向のアニメーション
    （Sequence2/03_Walk/03_Walk_Block）を使い分ける。
  ・攻撃を受け止めるたびにガードの耐久値が減り（GUARD の下の線）、0 になるとガードを崩される。
    崩されるとよろけて（AS_Block_Hit_Break）、2秒間ガードできない（画面に BREAK と点滅）。
    しばらく受け止めなければ、耐久値は少しずつ回復する。
  ・走っている時に Shift を押している間はダッシュ（走る速さが 1.6倍）。
    （止まっている時に Shift → ガード、走っている時に Shift → ダッシュ）


------------------------------------------------------------
 5. 画面の表示（左下）
------------------------------------------------------------
  ・モードの文字（オペレーターは「BLADE」で青、パニッシャーは「SLASH」でオレンジ）。固定中は下に赤い線。
  ・HP ゲージ
  ・ATB ゲージ2本：たまっている途中は青、満タンは金色で点滅、たまった瞬間は白く光る
  ・アビリティの枠「04」「05」（ゲージの右）
      金色で光る → 使える
      灰色 → ゲージが足りない
      上から暗い → CT 中（暗い部分がだんだん下がっていき、無くなったら使える）
      下の点の数 → 使う ATB ゲージの本数


------------------------------------------------------------
 6. ヒットストップ
------------------------------------------------------------
  ・攻撃が当たった瞬間に、プレイヤーと敵を数フレームだけ止めて、カメラを少し揺らす。
  ・ゲーム全体で1つの仕組み（Src/Application/Utility/HitStop.h）にして、
    すべての攻撃に同じルールでかけている。
      普通の攻撃：4フレーム、クリティカル：7フレーム
      パニッシャー・アビリティ：+2フレーム
      敵の攻撃を受けた時：6フレーム、ガードした時：4フレーム


------------------------------------------------------------
 7. カメラ
------------------------------------------------------------
  ・左右に移動すると、カメラもその方向へゆっくり回り込み、注視点も進む方向へ少しずれる
    （右へ走ると、右側が見えやすくなる）。


------------------------------------------------------------
 8. 調整したい時（数字を変える場所）
------------------------------------------------------------
  Player.cpp の上の方
    kOperatorAttackType / kPunisherAttackType ：モードごとの左クリックの攻撃（01・02）
    kAbilityInfos         ：アビリティの攻撃・使うゲージの本数・CT
    kCommandTimeScale     ：ATB コマンドを開いている間の時間の速さ（0.1）
    kModeLockFrame        ：攻撃05の後にオペレーターに固定する時間（5秒）
    kAtbPassiveGain / kAtbHitGain ：ATB ゲージのたまり方
    kHitStopFrame など    ：ヒットストップの長さ・カメラの揺れの強さ
    kGuardDamageRate      ：ガード中に受けるダメージの倍率（0.2）
    kGuardMoveRate        ：ガードしながら歩く速さ（普段の走る速さの 0.5倍）
    kGuardCostPerDamage   ：受け止めた時にガードの耐久値が減る量（ダメージ × 3）
    kGuardBreakFrame      ：崩された後、ガードできない時間（2秒）
    kPunisherMoveRate     ：パニッシャーの移動の速さ（0.7）

  PlayerState.cpp の上の方
    kAbilityDamageRate    ：アビリティのダメージ倍率（1.5）
    kAttack5_3AnimSpeed   ：攻撃05の3段目の再生速度（0.9）
    kDashSpeedRate        ：ダッシュの速さ（1.6）
    kGuardStartAnimSpeed  ：ガードを構える速さ（1.5）
    kGuardEndCancelRate   ：構えを解いている途中で、次の行動に移れるタイミング（0.3）

  TPSCamera.cpp の上の方
    kSideTurnRate / kLookAheadRate ：左右に動いた時にカメラが付いていく強さ

  EffectPlayer.h
    ModeChange / AbilityStart / Guard ：モード切り替え・アビリティ発動・ガードのエフェクト
    （今は "" で何も出ない。好きな .efkefc のファイル名を入れると出るようになる）

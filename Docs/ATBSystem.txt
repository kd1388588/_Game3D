============================================================
 バトルの仕組み（FF7リメイク風）の説明
============================================================
※今のコードに合わせて書いている（数値は PlayerConstants.h / PlayerStateConstants.h の値）

■ 一言で
  ・E キーで「オペレーター」と「パニッシャー」の2つのモードを切り替える。
    オペレーターの攻撃は攻撃01、パニッシャーは攻撃02。
  ・攻撃を当てる・回避すると ATB ゲージ（2本）がたまる（時間ではたまらない）。
    Space で「ATB コマンド」を開くと時間がゆっくりになり（10分の1）、
    技を選ぶと最後の段まで自動で出す。使った後は CT（クールタイム）がある。
  ・攻撃05（HIGH SPEED EDGE）を使った後は、5秒間オペレーターに固定される。
  ・右クリックで回避。Shift は移動中ならダッシュ、止まっていればガード。
  ・近くの敵には自動でロックオンする（10m 以内の一番近い敵。キーは無い）。
  ・攻撃が当たると、ヒットストップ（一瞬止まって画面が揺れる）がかかる。


------------------------------------------------------------
 1. 操作（キーの割り当ては InputHelper.h の Bind）
------------------------------------------------------------
                      キーボード・マウス            パッド
  移動                WASD                          左スティック
  攻撃                F / 左クリック                X
  回避                R / 右クリック                B
  ダッシュ / ガード   Shift                         RB
  モード切り替え      E / ホイールのクリック        Y
  ATB コマンド        Space（開く・閉じる）         A（開く。開いている間は決定）
  必殺技（すぐ出す）  1 / 2                         LB ＋ X / Y

  ATB コマンドを開いている間
    選ぶ    ：W / S・↑ / ↓（パッド：十字キー・左スティック）
    決定    ：Enter・左クリック・F（パッド：A・X）
    閉じる  ：Space・右クリック・R・BackSpace（パッド：B）
    1 / 2   ：その技をすぐ決定

  ※ジャンプのキーは無い（ジャンプは、攻撃04の叩きつけなど、技の中で跳ぶ）
  ※右クリックの回避は、パニッシャーのままでも出せる（モードは変わらない）。
    PlayerStateConstants.h の kEvadeReturnsToOperator を true にすると、
    FF7R のクラウドと同じく、オペレーターに戻ってから回避する


------------------------------------------------------------
 2. 2つのモードの違い
------------------------------------------------------------
                      オペレーター（BLADE）  パニッシャー（SLASH）
  左クリックの攻撃    攻撃01                 攻撃02
  移動の速さ          普通（1.0倍）          遅い（0.6倍）
  攻撃の速さ          速い（1.2倍）          遅い（0.8倍）
  与えるダメージ      低い（0.6倍）          高い（1.6倍）
  受けるダメージ      普通（1.0倍）          多い（1.3倍）
  ATB（当てた時）     2.5 × 1.15             2.5 × 0.75
  ヒットストップ      普通                   少し長い（+2フレーム。重い攻撃に見せる）

  ・ダメージ：普通の攻撃 3、クリティカル 5 に、モードの倍率をかけて四捨五入
      オペレーター：2（クリティカル 3）／ パニッシャー：5（クリティカル 8）
  ・二刀流なので、1振りで左右の剣がそれぞれ当たる。同じ剣は 10フレームあければ、もう一度当たる
  ・モードを切り替えた後は、3秒間切り替えられない（クールタイム）
  ・切り替えると、体のふちがモードの色（青・オレンジ）に光り、足元にエフェクトが出る


------------------------------------------------------------
 3. ATB ゲージと ATB コマンド（Space）
------------------------------------------------------------
  ・ATB ゲージは 2本（1本 = 100）。時間ではたまらない。
      攻撃を当てる：2.5（オペレーター × 1.15、パニッシャー × 0.75、クリティカル × 1.25）
      回避する　　：5（20回で1本）
      技（アビリティ）の攻撃を当てても、たまらない（無限に出せないように）
  ・Space でメニューを開くと、時間が10分の1の速さになる（キャラ・敵・エフェクトがゆっくり動く）。
    画面が少し暗くなり、右下にメニューが出る。敵はその間、攻撃してこない。
  ・選べる技（上から）
      HIGH SPEED EDGE：攻撃05。ATB ゲージ1本、CT 15秒。使った後5秒オペレーター固定
      SLASH RUSH     ：攻撃04。ATB ゲージ2本、CT 20秒
    ゲージが足りない・CT 中の技は灰色で、選んでも出ない（CT の残りは青い線で表示）。
  ・技を選ぶとメニューが閉じて時間が元に戻り、選んだ技を最後の段まで自動で出す。
  ・1 / 2 キーなら、メニューを開かずにすぐ出せる（ゲージ・CT はメニューと同じ）。
  ・技のダメージは、普通の攻撃の 1.5倍（モードの倍率はかからない）。
  ・技を受けた敵は、のけぞり続ける（当たるたびに 50フレーム延びる。その間は攻撃してこない）。
  ・攻撃05の3段目は、再生速度を下げている（0.75倍）。


------------------------------------------------------------
 4. ガードとダッシュ（Shift）
------------------------------------------------------------
  ・止まっている時に Shift を押している間はガード。
    受けるダメージが 2割になり、のけぞらない（画面のモードの文字の右に GUARD と出る）。
    アニメーションは Sequence2/08_Hit/14_Block の「構える（Start）→ 構えたまま（Loop）→ 解く（End）」。
    攻撃を受け止めた時は「受け止める（Hit）」を再生し、Shift を押したままなら構えに戻る。
  ・ガードを構えた後に移動キーを押すと、構えたまま歩ける（普段の走る速さの半分）。
    歩いている間はカメラの方を向いたままで、移動の方向に合わせて8方向のアニメーション
    （Sequence2/03_Walk/03_Walk_Block）を使い分ける。
  ・攻撃を受け止めるたびにガードの耐久値が減り（GUARD の下の線。ダメージ × 3）、0 になるとガードを崩される。
    崩されるとよろけて（AS_Block_Hit_Break）、2秒間ガードできない（画面に BREAK と点滅）。
    最後に受け止めてから 2秒たつと、耐久値は少しずつ回復する（0 から満タンまで約11秒）。
  ・走っている時に Shift を押している間はダッシュ（走る速さが 1.6倍）。
  ・回避の途中で攻撃を受けた時は、ダメージが半分になる。


------------------------------------------------------------
 5. 画面の表示（左下）　※位置・色の細かい値は UI_Elements.txt
------------------------------------------------------------
  ・モードの文字（BLADE は水色、SLASH はオレンジ）。切り替えられない間は、下に赤い線。
  ・HP ゲージ（HP が少ないと、赤とオレンジで点滅する）
  ・ATB ゲージ2本：たまっている途中は青、満タンは金色で明るさが波打つ、たまった瞬間は白く光る
  ・技の枠「05」「04」（HP ゲージの右）
      金色で光る → 使える
      灰色 → ゲージが足りない
      上から暗い → CT 中（暗い部分がだんだん下がっていき、無くなったら使える）
      枠の中の点の数 → 使う ATB ゲージの本数


------------------------------------------------------------
 6. ヒットストップ
------------------------------------------------------------
  ・攻撃が当たった瞬間に、プレイヤーと敵を数フレームだけ止めて、カメラを少し揺らす。
  ・ゲーム全体で1つの仕組み（Src/Application/Utility/HitStop.h）にして、
    すべての攻撃に同じルールでかけている。
      普通の攻撃：4フレーム、クリティカル：7フレーム
      パニッシャー・技：+2フレーム
      敵の攻撃を受けた時：6フレーム、ガードした時：4フレーム、ガードを崩された時：10フレーム


------------------------------------------------------------
 7. カメラ
------------------------------------------------------------
  ・左右に移動すると、カメラもその方向へゆっくり回り込み、注視点も進む方向へ少しずれる
    （右へ走ると、右側が見えやすくなる）。
  ・ロックオン中は、敵の方へ弱く回る（自分でもカメラを動かせる）。


------------------------------------------------------------
 8. 調整したい時（数字を変える場所）
------------------------------------------------------------
  PlayerConstants.h
    kOperatorAttackType / kPunisherAttackType ：モードごとの左クリックの攻撃（01・02）
    kOperatorDamageRate / kPunisherDamageRate ：モードのダメージの倍率（0.6・1.6）
    kOperatorAttackSpeedRate / kPunisherAttackSpeedRate ：モードの攻撃の速さ（1.2・0.8）
    kPunisherTakenDamageRate：パニッシャーの時に受けるダメージの倍率（1.3）
    kPunisherMoveRate     ：パニッシャーの移動の速さ（0.6）
    atbHitGain / atbEvadeGain   ：ATB ゲージのたまり方（当てた時 2.5・回避 5。StageSettings::PlayerTuning。Object Editor の「Player」タブで変える）
    kAbilityInfos         ：技の攻撃・使うゲージの本数・CT
    kCommandTimeScale     ：ATB コマンドを開いている間の時間の速さ（0.1）
    kModeLockFrame        ：攻撃05の後にオペレーターに固定する時間（5秒）
    kModeSwitchCoolFrame  ：モードを切り替えた後、次に切り替えられるまでの時間（3秒）
    kHitStopFrame など    ：ヒットストップの長さ・カメラの揺れの強さ
    kGuardDamageRate      ：ガード中に受けるダメージの倍率（0.2）
    kGuardMoveRate        ：ガードしながら歩く速さ（普段の走る速さの 0.5倍）
    kGuardCostPerDamage   ：受け止めた時にガードの耐久値が減る量（ダメージ × 3）
    kGuardBreakFrame      ：崩された後、ガードできない時間（2秒）
    kEvadeDamageRate      ：回避中に受けるダメージの倍率（0.5）

  PlayerStateConstants.h
    kAbilityDamageRate    ：技のダメージ倍率（1.5）
    kAttackAnimSpeed      ：攻撃の再生速度（1.3）
    kAttack5_3AnimSpeed   ：攻撃05の3段目の再生速度（0.75）
    kAttackEvadeCancelFrame ：攻撃のこのフレーム以降なら、回避でキャンセルできる（10）
    kAttackRecoveryFrame  ：攻撃の後のすきを、移動でキャンセルできるまでのフレーム（3）
    kMaxComboStep         ：コンボの段数（4。どの攻撃もアニメーションは 4 段目まで）
    kComboRestartFrame    ：最後の段の後、攻撃で 1 段目からつなげられるまでのフレーム（次の段へ進めるフレーム ＋ 8）
    kEvadeReturnsToOperator ：回避でオペレーターに戻すか（false）
    kDashSpeedRate        ：ダッシュの速さ（1.6）
    kGuardStartAnimSpeed  ：ガードを構える速さ（1.5）
    kGuardEndCancelRate   ：構えを解いている途中で、次の行動に移れるタイミング（0.3）

  TPSCamera.cpp の上の方
    kSideTurnRate / kLookAheadRate ：左右に動いた時にカメラが付いていく強さ

  EffectPlayer.h
    ModeChange / AbilityStart / Guard / GuardBreak ：モード切り替え・技の発動・ガード・ガードブレイクのエフェクト
    エフェクトの大きさ・速さ・色は、F8 のエフェクトエディタで変えられる（EffectSettings.json に保存）

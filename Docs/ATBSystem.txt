============================================================
 バトルモードと ATB ゲージ（FF7リメイク風）の説明
============================================================

■ 一言で
  ・E キーで「オペレーター」と「パニッシャー」の2つのモードを切り替える。
  ・攻撃を当てると ATB ゲージ（2本）がたまり、右クリックでゲージを1本使って
    アビリティ（強い技）を出せる。
  ・プレイヤーは常に剣を抜いた状態。剣を納める処理とアニメーションは
    プログラムから削除した（ファイルは Asset フォルダに残してある）。


------------------------------------------------------------
 1. 操作
------------------------------------------------------------
  E　　　　　：モード切り替え（オペレーター ⇔ パニッシャー）
  左クリック ：攻撃（続けて押すとコンボ）
  右クリック ：アビリティ（ATB ゲージを1本使う。足りない時はログに表示）
  C　　　　　：コンボの種類を切り替える（今のモードで使えるものの中で切り替わる）
  Shift　　　：回避（パニッシャーの時は、オペレーターに戻ってから回避する）


------------------------------------------------------------
 2. 2つのモードの違い
------------------------------------------------------------
                    オペレーター          パニッシャー
  移動の速さ        普通（1.0倍）         遅い（0.6倍）
  攻撃のダメージ    普通（1.0倍）         重い（1.5倍）
  ATB（時間）       少しずつたまる        たまらない
  ATB（当てた時）   +8                    +16（2倍）
  使えるコンボ      タイプ 1・2・3        タイプ 4・5
  アビリティ        Attack_1_4（連続斬り） Attack_4_4（重い一撃）

  ※ クリティカルの時は、当てた時にたまる量がさらに 1.5 倍。
  ※ アビリティの攻撃では ATB ゲージはたまらない（無限に出せないように）。


------------------------------------------------------------
 3. 画面の表示（左下、HP ゲージの上下）
------------------------------------------------------------
  ・HP ゲージの上に、今のモード（OPERATOR は青、PUNISHER はオレンジ）。
    切り替えた瞬間だけ文字が大きくなり、すぐ元に戻る。
  ・HP ゲージの下に、ATB ゲージ2本。
      たまっている途中 → 青
      満タン　　　　　 → 金色で、明るくなったり暗くなったりする（使える合図）
      たまった瞬間　　 → 一瞬白く光る


------------------------------------------------------------
 4. プログラムの場所
------------------------------------------------------------
  Player.h / Player.cpp
    ・BattleMode（モードの種類）、SetBattleMode（モードを変える）
    ・UpdateModeSwitch（E キーで切り替え）
    ・AddAtbGage / UseAtbBar / UpdateAtb（ATB ゲージをためる・使う・UI に伝える）
    ・AttackOBB（当たった時のダメージの倍率と、ATB ゲージをためる処理）

  PlayerState.h / PlayerState.cpp
    ・PlayerStateAbility（アビリティのステート。新しく追加）
    ・TryUseAbility（ゲージを1本使ってアビリティのステートへ）
    ・TryCommonTransition（待機・走り中の入力。E での抜刀・納刀を削除し、右クリックを追加）
    ・PlayerStateComboAttack（コンボ中の右クリックは「予約」し、キャンセルできるフレームで出す）

  UI/Gage/ATB/ATBGage.h / ATBGage.cpp（新しく追加）
    ・ゲージ2本とモードの文字を描く。画像は使わず、DrawBox（四角形）で描いている。

  削除したもの（プログラムからだけ。アニメーションのファイルは残してある）
    ・抜刀（Equip）・納刀（Unequip）・ダッシュ（Dash）のステート
    ・剣を納めている時の Idle / Run / Jump のアニメーションの読み込み
    ・鞘の位置の計算と、デバッグ画面の「Sheath」「Dash Speed」の項目
    ・WeaponState（剣を抜いているか）と GetWeaponAnimName（アニメ名の切り替え）


------------------------------------------------------------
 5. 調整したい時（数字を変える場所）
------------------------------------------------------------
  Player.cpp の上の方
    kOperatorAttackTypes / kPunisherAttackTypes ：モードごとに使えるコンボ
    kPunisherMoveRate     ：パニッシャーの移動の速さ（0.6）
    kPunisherDamageRate   ：パニッシャーのダメージ倍率（1.5）
    kAtbPassiveGain       ：オペレーターで時間でたまる量（1フレーム 0.05 → 約33秒で1本）
    kAtbHitGain           ：当てた時にたまる量（8）
    kPunisherAtbHitRate   ：パニッシャーで当てた時の倍率（2.0）

  PlayerState.cpp の上の方
    kOperatorAbilityAnim / kPunisherAbilityAnim ：アビリティで出す技のアニメーション
    kAbilityDamageRate    ：アビリティのダメージ倍率（2.5）
    kAbilityHitStopFrame  ：アビリティが当たった時に止まるフレーム数（4）

  EffectPlayer.h
    ModeChange / AbilityStart ：モード切り替え・アビリティ発動のエフェクト
    （今は "" で何も出ない。好きな .efkefc のファイル名を入れると出るようになる）


------------------------------------------------------------
 6. 発表で言うなら（台本例・30秒）
------------------------------------------------------------
  「FF7リメイクを参考に、2つのバトルモードと ATB ゲージを入れました。
    E キーで、素早く動けるオペレーターと、遅いけど一撃が重いパニッシャーを切り替えられます。
    攻撃を当てると ATB ゲージがたまり、パニッシャーの方がたくさんたまります。
    ゲージが1本たまると右クリックで大技が出せるので、
    『オペレーターで近づいて、パニッシャーで殴ってためて、大技で決める』という流れが作れます。」

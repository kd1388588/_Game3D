============================================================
エフェクトエディタと Effekseer との同期の使い方
============================================================

■ 開き方
  ゲーム中に F8 → 「Effect Editor」のウィンドウ

■ エフェクトごとの設定（Asset/Data/Effect の .efkefc が一覧に出る）
  ・大きさ・再生速度・高さのずれ
  ・色：「プレイヤーのモードで色を変える」にすると、オペレーター・パニッシャーで別の色になる
        （最初から、プレイヤーの斬撃（_Sword…）とモード切り替えはモードの色）
  ・色は「掛け算」。白（1.0）より明るくはできない。元のエフェクトに色が付いていると暗く濁るので、
    その時は Effekseer で元の色を白っぽくする
  ・「保存」で Asset/Data/EffectSettings.json に書き出し、次にゲームを始めた時に読み込む
  ・ここの値は、EffectPlayer でエフェクトを出す時に自動でかかる（コードを書き換えなくてよい）

■ 試し撃ち
  ・「選んだエフェクトを出す」：カメラの前にエフェクトを出す
  ・「続けて出す」：決めた間隔で出し続ける（Effekseer と同期しながら見るのに便利）
  ・色を確かめたい時は「オペレーター」「パニッシャー」を選ぶ（確認が終わったら「今のモードの色」に戻す）

■ Effekseer と同期（エディタで編集すると、動いているゲームにすぐ反映）
  1. Effect Editor の「Effekseer と同期」を開き、「同期を開始」を押す
     （初めての時は、Windows のファイアウォールの確認が出ることがある → 許可する）
  2. Effekseer エディタで、同じ名前のエフェクト（例：Asset/Data/Effect/_Sword1-1.efkefc）を開く
  3. エディタの「ネットワーク」ウィンドウで、ホスト 127.0.0.1・ポート 60000（Effect Editor の番号と同じ）に接続する
     （「自動で送信」をオンにすると、編集するたびに送られる）
  4. エディタで編集すると、ゲームの中のエフェクトが差し替わる。試し撃ちの「続けて出す」で確かめる
  5. よくなったら、Effekseer エディタで .efkefc を保存する
     ※同期で送った内容は、ゲームを終えると消える。保存を忘れないこと
  ・「ゲームを始めた時に自動で開始」にチェックして保存すると、次から自動で同期を始める
  ・どのエフェクトかは「ファイル名」で見分ける。エディタで開いたファイルと、ゲームが使うファイルの名前を同じにする

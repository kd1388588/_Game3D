============================================================
BRAVER　画面の要素（UI・HUD・画面の演出）の一覧
============================================================
※位置・大きさ・色は、各ファイルの上の方の定数（constexpr / const）で変えられる
※座標：画面の真ん中が原点 (0, 0)。右が +X、上が +Y。画面は 1280 × 720
        左はし x = -640、右はし x = 640、上はし y = 360、下はし y = -360
※色：{ 赤, 緑, 青, 不透明度 }（0.0 ～ 1.0）
※文字：UIText（Src/Application/GameObject/UI/Text/UIText.cpp）
        Small = 24px、Medium = 40px（フォント：Zen Old Mincho）
        Large = 96px・Title（フォント：Cinzel Static。英数字のみ）
        拡大率（SetScale）をかけて大きさを変える（例：Small × 0.6 = 約 14px）
※斜めの形（FF7R 風）：HudDraw.h（Src/Application/GameObject/Character/UI/Gage/Base/）
        2D の四角を行列で傾けて描く。パネルの傾き 0.27（約 15 度）、ゲージの傾き 0.8（約 39 度）

■ パネル（斜めの板）
  中心 (371, -293)、幅 470 × 高さ 66（kPanelCenterX / Y、kPanelHalfW / H。HPGage.h）
  左はし約 x = 136、右はし約 x = 606
  色：左 { 0.02, 0.06, 0.13, 0.88 } → 右 { 0.04, 0.11, 0.24, 0.72 } のグラデーション（16 本の帯）
  上の線 { 0.55, 0.82, 1.0, 0.6 }、下の線 { 0.55, 0.82, 1.0, 0.22 }（太さ 2px）

■ モードの色の斜めの線（パネルの左）　※ATBGage.cpp が描く
  x = 158（kAccentX）、太さ 4px（まわりに 10px のうっすらした光）、高さ 50
  色：オペレーター { 0.45, 0.8, 1.0 }（水色）／ パニッシャー { 1.0, 0.6, 0.2 }（オレンジ）

■ HP の数字
  右はし x = 470（kHpNumRightX）、y = -281（kHpNumY）
  Medium × 0.8（約 32px）。白
  「/ 100」：数字の右 6px、y = -286、Small × 0.55、白（不透明度 0.6）
  HP が少ない時（下の「点滅」）は、ゲージと同じ赤～オレンジで点滅

■ HP ゲージ（斜め）
  左はし x = 330、幅 175、y = -306、太さ 6（kHpBarLeft / Width / Y / Height）
  色：緑 { 0.45, 0.95, 0.6 }、背景 { 1, 1, 1, 0.12 }
  減った分：白 { 1, 1, 1, 0.55 } で残り、1 フレームに 4% ずつ縮む（kLagSpeed）

■ HP が少ない時の点滅
  HP の割合がステージエディタ「画面」タブの「HP が点滅し始める HP」（初期値 0.3）以下で始まる
  暗い赤 { 0.85, 0.18, 0.12 } ⇔ 明るいオレンジ { 1.0, 0.55, 0.3 } を行き来する
  速さ：「点滅の速さ」（初期値 0.12）
  ゲージのまわりに、うっすら赤い光 { 1.0, 0.3, 0.15, 0.35 }

1-3. ATB コマンドメニュー（画面の左下。開いている間だけ）
------------------------------------------------------------
ファイル：Src/Application/GameObject/Character/UI/Gage/ATB/ATBCommandMenu.cpp / .h

■ ウェイトモードの画面の色
  画面全体に、青っぽい暗い色 { 0.02, 0.1, 0.25, 0.3 } を重ねる
  （開いている間は時間がゆっくりになる。GameTime）
  開く・閉じる：1 フレームに 25% ずつ近づく（kOpenSpeed）

■ 後ろの板（斜め）
  中心 (-440, -262)、幅 360 × 高さ 124（kPanelCenterX / Y、kPanelHalfW / H）
  色：左 { 0.02, 0.06, 0.14, 0.85 } → 右 透明 のグラデーション。開く時は左から伸びる
  上の線 { 0.55, 0.82, 1.0, 0.55 }

■ 「ATB COMMAND」の文字
  左はし x = -595、y = -186、Small × 0.6、水色 { 0.65, 0.88, 1.0 }

■ 技の行
  1 行目 y = -232、2 行目 y = -274（間 42）。行の左はし x = -605、右はし x = -270、高さ 34
  技の名前：左はし x = -585、Small。「Attack1」「Attack2」
        選べる：白／選べない：灰色 { 0.45, 0.48, 0.55 }

■ 選んでいる行
  白 { 1, 1, 1, 0.95 } → 透明な水色 のグラデーションの斜めの帯（24 本の帯）
  文字は暗い紺 { 0.02, 0.08, 0.16 }（使えない時は薄く）
  左に白い三角（x = -625 あたり。左右に 3px ゆれる）

■ 使う ATB の本数
  行の右（右はし x = -290）に、斜めの印（幅 16 × 高さ 6）を本数だけ並べる
  使える：水色 { 0.45, 0.85, 1.0 }／使えない：薄い水色（不透明度 0.25）

■ CT の残り
  行の下に細い斜めの線（太さ 2）。水色 { 0.4, 0.75, 1.0 }。だんだん短くなる

■ 操作の説明
  左はし x = -595、y = -338、Small × 0.75、灰色
  「W/S：選択　左クリック：決定　右クリック：戻る」

1-4. 操作ガイド（画面の右上）
------------------------------------------------------------
ファイル：Src/Application/GameObject/UI/ControlsGuide/ControlsGuide.cpp
  パネル：右はし x = 625、下はし y = 185、幅 300（上はし約 y = 345）
        色 { 0.02, 0.03, 0.08, 0.55 }
  文字：Small × 0.75。行の間 20。キーは金色 { 1.0, 0.85, 0.4 }、動作は白っぽい灰色
  キーボードの時とパッドの時で、出す内容を切り替える
    キーボード：WASD 移動／F・左クリック 攻撃／R・右クリック 回避／Shift ダッシュ・ガード／
                E モード切り替え／Space ATBコマンド／1・2 必殺技
    パッド　　：左スティック 移動／X 攻撃／B 回避／RB ダッシュ・ガード／
                Y モード切り替え／A ATBコマンド／LB＋X・Y 必殺技
  ATB コマンドを開いている間と、倒れた後は、ふわっと消える（1 フレームに 10%）

2. 画面全体の演出（ポストエフェクト）

------------------------------------------------------------
2-1. HP が少ない時（白黒・暗く・周辺減光）
------------------------------------------------------------
ファイル：Src/Framework/Shader/PostProcessShader/KdPostProcessShader_PS_DoF.hlsl（色の処理）
          Src/Framework/Shader/PostProcessShader/KdPostProcessShader.h（SetScreenColor）
          Src/Application/GameObject/Character/Player/Player.cpp（UpdateHpGage で強さを決める）
調整：ステージエディタ（F8）の「画面」タブ（Asset/Data/StageSettings.json に保存）

  始まる HP：10%（startRate 0.1）。0 で一番強くなる
  HP 0 の時の強さ：白黒 0.85（少しだけ色が残る）、暗さ 0.35、周辺減光 0.97
  周辺減光の始まる位置：画面の真ん中から 0.25（0 で真ん中、1 で上下左右のはし）
  変わる速さ：1 フレームに 5%（約 1 秒でなじむ）
  HUD（2D）は後から描くので、白黒・暗くならない

------------------------------------------------------------
2-2. 倒れた時（真っ黒 → ゲームオーバー）
------------------------------------------------------------
ファイル：Player.cpp（UpdateHpGage）、Src/Application/Scene/GameScene/GameScene.cpp（CheckGameEnd）
  HP 0 で倒れると、途中まで暗くなっていた画面を「倒れて真っ黒になるまで」（初期値 1.5 秒）かけて真っ黒にする
  （始めと終わりをゆっくり）
  真っ黒になってから 20 フレーム（kGameOverWaitFrame）でゲームオーバー画面へ
  シーンが変わると、画面の色は元に戻る（SceneManager::ChangeScene）

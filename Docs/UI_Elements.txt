============================================================
BRAVER　画面の要素（UI・HUD・画面の演出）の一覧
============================================================
※今のコード（HUD は FF7R 風にする前の形）に合わせて書いている。今の状態の全体は CurrentState.txt
※位置・大きさ・色は、各ファイルの上の方の定数（constexpr / const）で変えられる
※座標：画面の真ん中が原点 (0, 0)。右が +X、上が +Y。画面は 1280 × 720
        左はし x = -640、右はし x = 640、上はし y = 360、下はし y = -360
※色：{ 赤, 緑, 青, 不透明度 }（0.0 ～ 1.0）
※文字：UIText（Src/Application/GameObject/UI/Text/UIText.cpp）
        Small = 24px、Medium = 40px（フォント：Zen Old Mincho）
        Large = 96px・Title（フォント：Cinzel Static。英数字のみ）
        拡大率（SetScale）をかけて大きさを変える（例：Small × 0.75 = 18px）
※2D の四角：KdSpriteShader の DrawBox（中心と、幅・高さの半分を整数で渡す）

1-1. HP ゲージ（画面の左下）
------------------------------------------------------------
ファイル：Src/Application/GameObject/Character/UI/Gage/HP/HPGage.cpp / .h

■ HP ゲージ
  左はし x = -500、中心の高さ y = -300（kGagePos）。幅 200 × 高さ 20（kGageWidth / Height）
  （右はし x = -300、上 y = -290、下 y = -310）
  背景：Asset/Textures/UI/Gage/BackGage.png（暗い茶色の半透明）
  中身：Asset/Textures/UI/Gage/HPGage.png（緑）。枠の太さ 2px の内側に、HP の割合だけの幅で描く
  （画像は Tools/MakeUITexture.py で作成）
  HP の数字は出していない

■ HP が少ない時の点滅
  HP の割合がステージエディタ「画面」タブの「HP が点滅し始める HP」（初期値 0.3）以下で始まる
  中身の画像の代わりに、暗い赤 { 0.85, 0.18, 0.12 } ⇔ 明るいオレンジ { 1.0, 0.55, 0.3 } の四角を描く
  速さ：「点滅の速さ」（初期値 0.12）
  まわりに 3px 大きい、うっすら赤い光 { 1.0, 0.3, 0.15, 0.35 }

■ ATB ゲージ（HP ゲージの下・2 本）
  1 本目：左はし x = -500、2 本目：左はし x = -396（幅 96、間 8）、中心 y = -322、高さ 10

  たまった瞬間：20 フレームだけ白く光る
  背景 { 0.05, 0.05, 0.1, 0.75 }、枠 { 0.6, 0.7, 0.85, 0.9 }

■ 技の枠（HP ゲージの右）
  「05」：中心 (-270, -311)、「04」：中心 (-228, -311)。大きさ 34 × 34
  使える時：金色の枠 { 1.0, 0.85, 0.3 } が光る。使えるようになった瞬間は白く光る
  使えない時：灰色の枠 { 0.4, 0.4, 0.45 }
  CT の残り：上から暗くする（黒 { 0, 0, 0, 0.65 }）
  使う ATB の本数：枠の中の下に、小さな四角の点
  ※キーの表示（E・F）は、画面をすっきりさせるために出していない

1-3. ATB コマンドメニュー（画面の右下。開いている間だけ）
------------------------------------------------------------
ファイル：Src/Application/GameObject/Character/UI/Gage/ATB/ATBCommandMenu.cpp / .h

■ 画面を暗くする
  画面全体に { 0.0, 0.0, 0.05, 0.35 } を重ねる（開いている間は時間がゆっくりになる。GameTime）
  開く・閉じる：1 フレームに 25% ずつ近づく（kOpenSpeed）

■ パネル
  中心 (420, -205)、幅 380 × 高さ 190（kPanelCenterX / Y、kPanelHalfW / H）
  （左はし x = 230、右はし x = 610、上 y = -110、下 y = -300）
  色 { 0.03, 0.05, 0.12, 0.85 }、枠 { 0.6, 0.75, 0.95, 0.9 }
  開く時は、幅 60% から横に広がる

■ 「ATB コマンド」の文字
  y = -132、Small、金色 { 1.0, 0.85, 0.3 }

■ 技の行
  1 行目 y = -175、2 行目 y = -217（間 42）
  技の名前：左はし x = 270、Small。「HIGH SPEED EDGE」（攻撃 05）「SLASH RUSH」（攻撃 04）
  使う本数：右はし x = 590、「ATB x1」「ATB x2」
  選べる：白／選べない（ゲージが足りない・CT 中）：灰色 { 0.45, 0.45, 0.5 }

■ 選んでいる行
  背景：金色の半透明 { 1.0, 0.85, 0.3, 0.3 }（高さ 34）
  左に金色の三角（名前の左 16px あたり。左右に 3px ゆれる）

■ CT の残り
  行の下に青い線 { 0.4, 0.7, 1.0 }（太さ 3）。だんだん短くなる

■ 操作の説明
  中心 x = 420、y = -277、Small × 0.75、灰色
  「W/S：選択　左クリック：決定　右クリック：戻る」

1-4. 操作ガイド（画面の右下）
------------------------------------------------------------
ファイル：Src/Application/GameObject/UI/ControlsGuide/ControlsGuide.cpp
  パネル：右はし x = 625、下はし y = -345、幅 300（7 行なので上はし約 y = -185）
        色 { 0.02, 0.03, 0.08, 0.55 }
  文字：Small × 0.75。行の間 20。キーは金色 { 1.0, 0.85, 0.4 }、操作は白っぽい灰色
  キーボードの時とパッドの時で、出す内容を切り替える
    キーボード：WASD 移動／F・左クリック 攻撃／R・右クリック 回避／Shift ダッシュ・ガード／
                E モード切り替え／Space ATBコマンド／1・2 必殺技
    パッド　　：左スティック 移動／X 攻撃／B 回避／RB ダッシュ・ガード／
                Y モード切り替え／A ATBコマンド／LB＋X・Y 必殺技
  ATB コマンドを開いている間（同じ右下に出るため）と、倒れた後は、ふわっと消える（1 フレームに 10%）

------------------------------------------------------------
2-1. HP が少ない時（白黒・暗く・周辺減光）
------------------------------------------------------------
ファイル：Src/Framework/Shader/PostProcessShader/KdPostProcessShader_PS_DoF.hlsl（色の処理）
          Src/Framework/Shader/PostProcessShader/KdPostProcessShader.h（SetScreenColor）
          Src/Application/GameObject/Character/Player/Player.cpp（UpdateHpGage で強さを決める）
調整：ステージエディタ（F8）の「画面」タブ（Asset/Data/StageSettings.json に保存）

  始まる HP：10%（startRate 0.1）。0 で一番強くなる
  HP 0 の時の強さ：白黒 0.85（少しだけ色が残る）、暗さ 0.35、周辺減光 0.97
  周辺減光の始まる位置：画面の真ん中から 0.25（0 で真ん中、1 で上下左右のはし）
  変わる速さ：1 フレームに 5%（約 1 秒でなじむ）
  HUD（2D）は後から描くので、白黒・暗くならない

------------------------------------------------------------
2-2. 倒れた時（真っ黒 → ゲームオーバー）
------------------------------------------------------------
ファイル：Player.cpp（UpdateHpGage）、Src/Application/Scene/GameScene/GameScene.cpp（CheckGameEnd）
  HP 0 で倒れると、途中まで暗くなっていた画面を「倒れて真っ黒になるまで」（初期値 1.5 秒）かけて真っ黒にする
  （始めと終わりをゆっくり）
  真っ黒になってから 20 フレーム（kGameOverWaitFrame）でゲームオーバー画面へ
  シーンが変わると、画面の色は元に戻る（SceneManager::ChangeScene）

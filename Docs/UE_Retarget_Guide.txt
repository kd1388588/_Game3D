============================================================
 SK_Assassin へのリターゲットと glTF 書き出しの手順（UE 5.4）
============================================================

対象
  モデル        ：/Game/Scifi_Assassin 内の SK_Assassin（骨は Manny/Quinn 系）
  アニメーション：/Game/Dual_Sword/Animations/Sequence2 以下すべて
  武器          ：SM_Blade（両手）・SM_Scabbard（背中にクロス）

できあがるもの
  UE 内
    /Game/ReTarget/IK/                       … IK Rig・IK Retargeter
    /Game/ReTarget/Dual_Sword/Animations/Sequence2/...
                                             … リターゲット後のアニメーション
                                               （元の Dual_Sword と同じフォルダ構成）
  書き出し先 C:\UE_gltf\Player\New
    CharaBase\SK_Assassin.gltf / .bin と テクスチャ
    CharaBase\SM_Blade.gltf / SM_Scabbard.gltf とテクスチャ
    Sequence2\01_Idle\...\<アニメ名>\<アニメ名>.gltf / .bin
                                             … アニメーション1つにつき1フォルダ
                                               （中身は .gltf と .bin のみ）

※ 作業前に必ずプロジェクトのバックアップを取ってください。


------------------------------------------------------------
1. 準備（最初の1回だけ）
------------------------------------------------------------

 1) メニュー「編集」→「プラグイン」で次の2つを検索して有効にし、UE を再起動
      ・Python Editor Script Plugin
      ・glTF Exporter
 2) 「編集」→「プロジェクト設定」→「Python」の
      「Developer Mode」にチェック（エラーの内容が分かりやすくなる）


------------------------------------------------------------
2. 武器用のソケットを作る（手作業）
------------------------------------------------------------

ゲームは、モデルの次の名前のノードに武器を取り付けます。
名前は大文字・小文字も含めて正確に合わせてください。

  ソケット名         付ける骨       付けるもの
  Weapon_R           hand_r         右手の SM_Blade
  Weapon_L           hand_l         左手の SM_Blade
  Weapon_Holder_R    spine_05       背中の SM_Scabbard（右肩から斜め）
  Weapon_Holder_L    spine_05       背中の SM_Scabbard（左肩から斜め）

 1) SK_Assassin をダブルクリックして開き、上部の「スケルトン」タブに切り替える
 2) 左のスケルトンツリーで hand_r を右クリック →「ソケットを追加」
    → 名前を Weapon_R に変更
 3) 作ったソケットを右クリック →「プレビューアセットを追加」→ SM_Blade
 4) ビューポートで剣が手のひらに正しく握られるように、ソケットの位置・回転を調整
 5) hand_l にも同じように Weapon_L を作る
 6) spine_05 に Weapon_Holder_R と Weapon_Holder_L を作り、それぞれ SM_Scabbard を
    プレビュー表示して、背中で X 字にクロスするように回転させる
      目安：片方を Roll（X）+45度、もう片方を -45度 にして、背中側へ少しずらす
 7) 「保存」を押す

確認のしかた
  ・プレビューのアニメーションで Sequence2 の納刀・抜刀のアニメーションを再生し、
    剣を鞘に収める瞬間に、剣先が鞘の口に合っているか確認する
  ・ずれる場合は鞘（Weapon_Holder_R/L）の位置・角度を調整する
  ・ゲーム側でも「Weapon Adjust」タブで細かく調整できるので、ここでは大まかでよい


------------------------------------------------------------
3. スクリプトの実行（リターゲットと書き出し）
------------------------------------------------------------

 1) Tools/UE/RetargetAndExport.py を PC の分かりやすい場所に置く
    （リポジトリを pull していれば、プロジェクトフォルダの Tools\UE の中にあります）
 2) UE 下部の「出力ログ」を開き、入力欄の左の「Cmd」をクリックして「Python」に切り替え
 3) 次のように入力して Enter（パスは / 区切り、自分の環境に合わせる）
        py "C:/3DGame_Braver/_Game3D/Tools/UE/RetargetAndExport.py"
 4) 出力ログに [Retarget] で始まるログが出ます。最後に「完了しました」と出れば成功です

スクリプトがやること
  ① Sequence2 のアニメーションが使っているスケルトンから、リターゲット元のモデルを探す
  ② IK Rig を2つ（元・先）と IK Retargeter を自動作成
     （Manny/Quinn 系の骨はチェーンを自動で作れるので、手作業は不要）
  ③ アニメーションを1つずつリターゲットし、元のフォルダ構成のまま
     /Game/ReTarget/Dual_Sword/... に保存（名前は元と同じ）
  ④ SK_Assassin・SM_Blade・SM_Scabbard をテクスチャ付きで CharaBase に書き出し
  ⑤ リターゲット後のアニメーションを1つにつき1フォルダで書き出し、
     フォルダの中を .gltf と .bin だけにする

設定を変えたいとき
  スクリプト冒頭の「設定」部分を書き換える
    ・リターゲットだけしたい      → DO_EXPORT = False
    ・書き出しだけやり直したい    → DO_RETARGET = False
    ・リターゲット元のモデルが見つからないと言われた
                                  → SOURCE_MESH_PATH にモデルのパスを書く
  2回目以降に実行すると、リターゲット済みのアニメーションはスキップされます。
  やり直したいときは /Game/ReTarget/Dual_Sword を削除してから実行してください。


------------------------------------------------------------
4. リターゲット結果の確認（違和感がないか）
------------------------------------------------------------

 1) /Game/ReTarget/IK/RTG_DualSword_to_SK_Assassin を開く
 2) 左が元、右が SK_Assassin。上部の再生ボタンでアニメーションを流して比較する
 3) よくある違和感と直し方
    ・腕が体にめり込む / 開きすぎる
        → 「リターゲットポーズを編集」で SK_Assassin の上腕の角度を元に合わせる
    ・足が地面から浮く / めり込む
        → 詳細パネルの Root の「Scale Vertical」や、Pelvis の「Translation Mode」を調整
    ・手首がねじれる
        → チェーン設定で該当チェーンの「FK Rotation Mode」を変える
 4) 直したら、/Game/ReTarget/Dual_Sword を削除してスクリプトを再実行すると、
    直した設定でリターゲットし直されます


------------------------------------------------------------
5. うまくいかないとき
------------------------------------------------------------

・スクリプトがエラーで止まった
    出力ログの赤い文字（Traceback から最後まで）をそのまま送ってください。修正します。
    ※ このスクリプトは UE を動かせない環境で書いたため、未検証です。

・スクリプトを使わずに手作業でリターゲットしたい（UE 5.4 の標準機能）
    1) Sequence2 のアニメーションを全て選択して右クリック
       →「アニメーションをリターゲット」
    2) 「ソース」に元のモデル、「ターゲット」に SK_Assassin を選ぶ
       （IK Retargeter は自動で作られます）
    3) 「出力パス」で /Game/ReTarget/Dual_Sword/Animations/Sequence2/... を選んで
       「アニメーションをエクスポート」
       ※ この方法だとサブフォルダごとに出力先を選び直す必要があります

・glTF の書き出しだけ手作業でやりたい
    アセットを右クリック →「アセットアクション」→「エクスポート」→ 形式で glTF を選択
    アニメーションは「Export Preview Mesh」にチェック、
    テクスチャの形式（Texture Image Format）を「None」にする

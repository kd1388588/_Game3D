============================================================
分類：戦闘の HUD・UI
ファイル：GameObject/Character/UI/Gage/ATB/ATBCommandMenu.cpp / .h

■ 使った技術
  ・開く・閉じる：1 フレームに 25% ずつ近づけて、なめらかにする（パネルは横に広がる）
  ・開いている間、画面全体を少し暗くする（時間がゆっくりなのを伝える）
  ・選んでいる行：金色の背景と、左右に揺れる三角（DrawTriangle）
  ・選べない技は灰色。CT の残りは行の下の青い線
  ・技の名前（HIGH SPEED EDGE / SLASH RUSH）と、使う本数（ATB x1 / x2）

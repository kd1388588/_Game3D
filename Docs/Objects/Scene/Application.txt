分類：アプリとシーン

■ 使った技術
  ・ゲームループ：1 秒に 60 回、PreUpdate → Update → PostUpdate → Draw を呼ぶ
  ・XInput：毎フレーム最初に 1 回だけパッドの状態を読む
  ・デバッグ表示の切り替え：F8 で imgui のウィンドウと当たり判定のワイヤーを出す
    （F12 は Visual Studio のブレークキーなので使わない）
  ・COM の初期化、日本語の文字変換の設定

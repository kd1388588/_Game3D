============================================================
Tools（ステージ・画像・音・エフェクトを作る Python のスクリプト）
============================================================
分類：Python のツール
ファイル：Tools/

■ 使った技術
  ・プロシージャル生成：ノイズでテクスチャを作る、三角形を組み立てて glTF で書き出す

■ スクリプトの一覧
  ・MakeCastleStage.py：今のステージ（6 つの部屋を通路でつなぐ）の形・当たり判定・光の位置と、上から見た地図（Docs/StageMap.png）
    （マス目に歩ける所を塗り、そのまわりを壁にする作り方。部品は MakeStageModel.py の物を使う）
  ・MakeKeyTexture.py：鍵の画像（光る金色の鍵）と、回復の泉の光の画像（水色の丸いにじみ）
  ・MakeStageModel.py：前のステージ（道・門楼・中庭・左右の部屋・大聖堂・玉座の間）の形と当たり判定を作る
  ・MakeNightSky.py：夜空と月の画像を作り、空のモデルに貼って書き出す
  ・MakeFlameTexture.py：松明の炎の画像
  ・MakeHeadingImages.py：GAME CLEAR / GAME OVER の見出しの画像
  ・MakeSoundAssets.py：mp3 を wav に変換する
  ・MakeEffekseerProjects.py：モード切り替え・アビリティ・ガード・敵を倒した時のエフェクト（.efkproj）を作る
    （Effekseer エディタで開いて、同じ名前の .efkefc に保存すると、ゲームで使える）
  ・AdjustExistingEffects.py：もとのエフェクトの数を減らす・短くする
  ・MakeGroundSmashEffect.py：ボスの着地のエフェクト
  ・MakeTrailTexture.py：剣の軌跡の画像
  ・MakeBarrierTexture.py / MakeShieldTexture.py / MakeImpactTexture.py：バリア・オーラ・衝撃の画像
  ・MakeUITexture.py / MakeResultBackground.py / MakeHeadingFont.py：UI の画像・結果画面の背景・見出しの文字
